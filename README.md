# Bill Payment Tracker

A simple tool that helps you keep track of your monthly bills — how much you owe, what you've already paid, and how much money you'll have left. Everything happens in one page that runs right in your web browser.

## What's in this folder

| File / Folder | What it is |
|---|---|
| `index.html` | **The app itself.** Double-click this to open and use it. |
| `style.css` | Controls how the app looks — colors, spacing, fonts. |
| `app.js` | Controls how the app works — adding bills, doing the math, saving your data. |
| `tests/` | A set of automatic checks that make sure the app works correctly. |
| `design_handoff_bill_tracker/` | The original design plans this app was built from. |
| `APP.md` | A plain-language guide to everything the app can do. |
| `DESIGN.md` | A plain-language guide to how the app looks, and why. |
| `TESTING.md` | A plain-language guide to how we check the app isn't broken. |

## How to use it

1. Find **`index.html`** in this folder and double-click it.
2. It opens in your web browser — Chrome, Firefox, Edge, or Safari all work fine.
3. Type in your starting balance, add your bills, and the app takes care of the math.

There's nothing to install and no account to create. The only time it needs the internet is a brief moment when it first loads two nice-looking fonts — after that, it works completely offline. Everything you type is automatically saved on your own computer (inside your browser), so your bills and balances are still there the next time you open it.
